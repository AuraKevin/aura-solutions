# My Portfolio

Welcome to my personal portfolio website! This website showcases my skills, projects, and contact information. It was created to provide an overview of my work as a web developer.

## Features

- **Responsive Design**: The site is fully responsive and looks great on desktop, tablet, and mobile devices.
- **Project Showcase**: Display of various web development projects I've worked on.
- **Contact Form**: A simple contact form for getting in touch with me directly.

## Technologies Used

- **HTML**: For the structure of the webpage.
- **CSS**: For styling the webpage, making it responsive, and adding visual appeal.
- **JavaScript** (optional): If you plan to add interactivity or features.
